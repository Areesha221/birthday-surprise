## 📌 Project Overview

This application transforms a standard greeting into an immersive, cinematic web experience. Built with modern frontend architecture, it focuses on performance, responsiveness, and micro-interactions to create an emotional connection with the end-user. 

## ✨ Key Features

- **Cinematic Onboarding:** Custom cursor effects and interactive envelope opening sequence.
- **Dynamic Typewriter Engine:** Auto-scrolling, real-time text rendering for the personal letter.
- **Audio-Visual Synchronization:** Seamless background music integration with context-aware volume fading (e.g., lowering background audio when voice notes play).
- **Interactive Media Gallery:** Polaroid-style memory wall with hover states and lightbox previews.
- **Real-Time Countdown Engine:** Precise millisecond calculation with automated confetti triggers upon target completion.
- **Glassmorphism UI:** Premium aesthetic using backdrop filters, gradients, and custom shadows.
- **Fully Responsive:** Optimized layout and touch interactions for mobile, tablet, and desktop.
